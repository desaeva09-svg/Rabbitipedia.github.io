Propósito del sitio

Rabbitipedia es un sitio web creado para compartir información y curiosidades sobre los conejos de una manera sencilla y entretenida. La página busca presentar información sobre estos animales utilizando un diseño visual relacionado con el tema.

Este sitio fue realizado como parte de una actividad para aprender a crear, publicar y actualizar una página web utilizando GitHub Pages.

Tecnologías utilizadas
HTML: Para crear la estructura y organizar el contenido de la página.
CSS: Para agregar el diseño, colores, fondos, tamaños y estilos.
JavaScript (JS): Para agregar funciones e interacciones al sitio.
jQuery: Para facilitar algunas funciones de JavaScript.
